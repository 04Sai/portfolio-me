# Portfolio Website

A personal portfolio website built with React, TypeScript, and Vite.

## Overview

This project showcases:

- A landing section with personal intro and skills
- A Projects section with image-first cards and load-more behavior
- Individual project detail pages with media previews and previous/next navigation
- Smooth scrolling interactions and route transitions

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion / Motion
- Zustand
- React Router
- Three.js + React Three Fiber + Drei
- Lenis (smooth scrolling)

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start development server

```bash
npm run dev
```

### 3. Build for production

```bash
npm run build
```

### 4. Preview production build

```bash
npm run preview
```

## Available Scripts

- `npm run dev`: start local dev server
- `npm run build`: type-check and create production build
- `npm run lint`: run ESLint
- `npm run preview`: preview production build locally
